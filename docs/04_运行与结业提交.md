## 本地运行

- 使用的操作系统和环境版本为 `Windows 11 + WSL2（Ubuntu 26.04）、Python 3.12、Node.js 24、npm 11`。
- 前后端启动顺序为 `先后端（8000），再前端（5173）`。
- 页面入口为 `[XXX](http://localhost:5173)`，后端 API 地址为 `[XXX](http://127.0.0.1:8000)`。
- 启动后执行 `点击四个方向按钮`，预期看到 `机器人移动、状态同步；朝障碍前进时提示「前方是障碍物，机器人保持原位」`。

依赖安装、配置、启动命令和单端验证步骤分别见[前端 README](../frontend/README.md)与[后端 README](../backend/README.md)。

## Docker 部署

1. 从 `XXX` 目录执行命令，所需 Docker 环境为 `Docker 24+（Docker Desktop 4.x，WSL2 后端）`。
2. 无需额外配置：基础版不依赖外部密钥，镜像内置前端静态产物与后端服务。
3. 使用 `docker pull ghcr.io/gujianxiaozi1234/patrol-sim:latest` 构建或获取镜像，再执行 `docker run -d --name patrol -p 8000:8000 ghcr.io/gujianxiaozi1234/patrol-sim:latest` 启动服务。
4. 打开 `[XXX](http://localhost:8000)`，执行 `点击「前进 / 后退 / 左转 / 右转」` 验证页面和 API，预期结果为 `预期：页面加载二维地图与机器人、操作后机器人移动且状态同步、撞障碍时提示「前方是障碍物，机器人保持原位」。`。
5. 使用 `docker rm -f patrol` 停止服务。
